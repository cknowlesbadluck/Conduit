1. **High — permanently red external check.** Workers Builds fails on main and every PR, training everyone to ignore red CI.
2. **High — two app entrypoints.** `src/index.ts` and `src/app-factory.ts` each wire routes/auth independently; tests mostly exercise the factory while production runs `index.ts`. Drift risk on auth paths.
3. **High — DB TLS not verified by default** (#155/#162, issue #201).
4. **Medium — no ordered migrations** (draft #120); schema DDL inline in `store.ts` (653 lines, dense one-line functions).
5. **Medium — unauthenticated `/diagnostics` and `/status`.** `/diagnostics` triggers outbound fetches to Descope per request (amplification); `/status` exposes live counts (agents, tasks, activity).
6. **Medium — PR backlog**: 14+ open PRs, several conflicting (#187, #190, #193).
7. **Low — `integration_call` body is `z.unknown()`**; relies on adapter policy for safety.
8. **Low — portfolio docs/scripts live in a product repo** (posture classifier, portfolio roadmap) — scope creep against README non-goals.
